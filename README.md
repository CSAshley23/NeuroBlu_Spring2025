# USI Spring 2025 CS Capstone Project Outline: 
## Detecting and Cleaning Invalid Days_Supply in NeuroBlu Drug Records Using Machine Learning  

### Project Overview  
The goal of this project is to develop a **machine learning (ML) model** that detects and corrects **invalid or incorrect** days_supply values in the **drug_exposure** table of **NeuroBlu**.  

### Important Files to Review  

- **Tyler's Branch:**  
  - `xgboost.py` – Contains the implementation of the machine learning model.  
  - Multiple versions of the model with different approaches, including comorbidity analysis.  

- **Ashley's Branch:**  
  - `Model_1_Ashley.py` – Demonstrates how SHAP was integrated with XGBoost to explain model predictions.  

- **Chase's Branch:**  
  - Contains SQL queries used for data extraction and preprocessing.  

### Notes  
- Each branch provides different aspects of the project, focusing on machine learning, explainability, and data manipulation using SQL.  
- SHAP analysis in Ashley’s branch helps interpret feature importance in model predictions.
